# 商米 Kiosk 维护

客服使用启用了 STEADDESK_POWER_MENU 的 Windows 客服包，连接获准维护的 Android 商户端。在返回、主页和最近任务旁点击「电源菜单」，核对设备后确认。Android 会显示由系统提供的菜单，成功调出时设备显示提示。取消确认后可继续原会话。

只有现场政策允许、商户同意维护时才选择厂商提供的 Exit Kiosk，按厂商正常验证流程完成维护。由获授权人员输入 PIN，避免将 PIN 写进备注、截图或工单。完成维护后按原配置重新启用 Kiosk，确认 POS 返回、组策略恢复、两端仍可连接并记录维护时间。

Jason 于 2026-11-17 在 OrderPAD 3 验证：进入 Kiosk 并打开应用期间，客服会话保持连接。电源菜单显示 Exit Kiosk，远程点击后输入管理 PIN 能正常退出。用 Windows sd.5 客服端点击电源菜单按钮并确认后，OrderPAD 3 弹出系统电源菜单，菜单中有 Exit Kiosk。客服远程点击 Exit Kiosk 并输入管理 PIN，平板成功退出 Kiosk。

其他商米机型及合作伙伴平台下发 Kiosk 的允许名单仍待实测。下发前由设备管理员核对商户端与 Agent 是否均获准运行。远程操作不可用时，由在场管理员按原设备管理流程恢复。
